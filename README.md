# Smart Tank Auto Motor Control

## About
Smart Tank is an automatic water level and motor control system.

It helps monitor the water tank level and controls the motor automatically.

## Features
- Automatic water level monitoring
- Automatic motor ON/OFF control
- Simple and user-friendly interface
- Helps prevent water overflow

## Technologies Used
- HTML
- CSS
- JavaScript

## Project
This project is developed to provide a simple solution for automatic water tank monitoring and motor control.
